# هناك رسالة تنتظركِ 💌

موقع عربي تفاعلي برسائل تحفيزية إنجليزية، ولوحة معلمة لإدارة أسماء الطالبات والرسائل.

## التشغيل محليًا

1. ثبتي Node.js إصدار 20 أو أحدث.
2. افتحي مجلد المشروع في Terminal.
3. نفذي `npm install`.
4. انسخي `.env.example` إلى `.env` وغيري `ADMIN_PIN` إلى رمز خاص **طويل لا يقل عن 8 أحرف**.
5. نفذي `npm start` ثم افتحي `http://localhost:3000`.

## النشر للطالبات

- الموقع يحتاج استضافة تدعم تشغيل Node.js (وليس GitHub Pages/Netlify static فقط) مثل Render أو Railway.
- ارفعي ملفات المشروع لاستضافة Node.js، واجعلي أمر التشغيل `npm start`.
- أضيفي متغير البيئة `ADMIN_PIN` في إعدادات الاستضافة بدل نشر ملف `.env`.
- أضيفي `SECURE_COOKIES=1` عند استخدام HTTPS.
- احرصي على ربط مجلد `DATA_DIR` بتخزين دائم، حتى لا تضيع إضافات الطالبات عند إعادة تشغيل الاستضافة أو إعادة نشر الموقع.
- يمكنكِ نسخ احتياطي من زر **تصدير JSON** في لوحة المعلمة.

## بيانات الطالبات

- ملف `seed-data.json` يحتوي **قائمة أولية قابلة للمراجعة** جمعت من الأسماء التي شاركتِها المعلمة سابقًا لفصول السادس؛ هذه ليست كشفًا رسميًا نهائيًا. بعض الأسماء قد تتشابه بين الفصول، فيرجى التأكد منها قبل النشر.
- عند تشغيل الخادم أول مرة، تُنسخ الأسماء إلى `data/students.json` وتُوزع رسائل مختلفة بالإنجليزية. أي تعديل لاحق يُحفظ بالخادم ولا يحتاج لتعديل الكود.
- إذا كررت طالبتان الاسم نفسه في فصلين مختلفين، يعرض الاستعلام باسم فقط رسالة عامة حفاظًا على عدم إظهار رسالة لطالبة أخرى. يمكن لاحقًا إضافة اختيار الفصل لتحسين المطابقة.
- يمكن إضافة أسماء من لوحة المعلمة، أو لصق قائمة اسمًا في كل سطر.

## الخصوصية والأمان

- أسماء الطالبات ورسائلهن لا تُرسل إلى واجهة الزائرة ضمن القائمة الكاملة، ولا توجد API عامة لإظهار الأسماء.
- تُحفظ البيانات على الخادم، ويحميها رمز معلمة مع حد للمحاولات، وجلسة HttpOnly.
- **مهم:** مجرد معرفة الاسم تكفي لفتح رسالته؛ لذلك لا تضعي بيانات أو معلومات شخصية حساسة في نص الرسالة. إن أردتِ خصوصية كاملة لكل طالبة، يلزم إضافة رمز فردي خاص لكل طالبة.
- يستحسن عدم نشر ملفات `.env` و`data/` في مستودع عام، وعدم رفع صور خاصة للطالبات.
- ينصح بإضافة نسخ احتياطية ودخول HTTPS قبل استخدام الموقع على نطاق واسع.

## تخصيص التصميم

التصميم والحركات في `public/index.html`. جميع الرسائل في الإنجليزية وتوقيع المعلمة ثابت: `Your teacher: Seham Alshahrani 💗`.
